Lens Loop — Privacy Policy

Effective 1 October 2026

Lens Loop is a personal web application published by Ahmet Kartal at ahmetkartal-99.github.io/lens-loop. It runs entirely in the user's own browser. There is no Lens Loop server: the operator receives no data from the application.

What the application processes

  • Camera frames are captured on the device and sent, together with the user's saved transcripts, to Anthropic's API (api.anthropic.com) to obtain an answer. Frames are not stored by the application beyond a small thumbnail kept in the current session.
  • Microphone audio is streamed from the device to ElevenLabs (api.elevenlabs.io) for speech recognition when the user has entered an ElevenLabs API key, or is transcribed by the device's own dictation engine otherwise. The application keeps the resulting text, not the audio.
  • Transcripts ("storylines"), their titles and summaries, and the user's settings and API keys are stored in the browser's storage on the user's device.

Google user data

If the user chooses to connect Google Drive, the application requests the drive.file scope. With it, the application can only create, read, update and delete files that it created itself, inside a folder named "Lens Loop" in the user's own Google Drive. It cannot see any other file in the user's Drive. The files it writes are copies of the user's transcripts, titles and summaries, so that they are backed up and available on the user's other devices.

The Google access token is kept in the browser's storage on the device and is used only to call the Google Drive API from the device. Google user data is never sent to the operator or to any third party, is not used for advertising, is not sold, and is not used for any purpose other than the backup and restore of the user's own transcripts described above. The user can revoke access at any time with the "Disconnect" control in the application or at myaccount.google.com/permissions, and can delete the "Lens Loop" folder from their Drive at any time.

Lens Loop's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Third-party services

Data sent to Anthropic, ElevenLabs and Google is handled under those providers' own terms and privacy policies. The application sends nothing to any other service and contains no analytics or tracking.

Retention and deletion

All application data lives on the user's device and, if connected, in the user's own Google Drive. Deleting a storyline in the application removes it from the device and moves the Drive copy to the trash. Clearing the browser's site data, or removing the Home Screen app, removes everything stored on the device.
